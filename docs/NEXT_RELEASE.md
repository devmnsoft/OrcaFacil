# Next Release

Funcionalidades candidatas para a próxima versão após estabilização dos fluxos críticos:

1. Catálogo completo de serviços salvos com CRUD, busca e uso direto em orçamento.
2. Pipeline comercial, follow-ups e timeline, hoje não integrados ao ASP.NET.
3. Versionamento completo de documentos com diff, restauração e auditoria.
4. Exportação LGPD self-service e workflow operacional de exclusão de conta.
5. Relatórios avançados e exportáveis para usuário e SuperAdmin.
6. Cobertura E2E automatizada com banco PostgreSQL em container.
7. Validação visual automatizada com axe/Lighthouse além do script de contraste.
