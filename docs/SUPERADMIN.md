# SuperAdmin

A área `/Admin` é protegida por policy `SuperAdmin`. O dashboard exibe usuários totais/ativos/bloqueados/Free/Pro/inadimplentes, clientes, documentos, orçamentos, recibos, PDFs, pagamentos, receita do mês, MRR estimado, atividade, financeiro, inadimplência e saúde do sistema.

Menus disponíveis: Dashboard Admin, Usuários, Clientes dos usuários, Planos, Pagamentos, Inadimplentes, Mercado Pago, Webhooks, Logs, Erros, Banco de Dados e Configurações.
